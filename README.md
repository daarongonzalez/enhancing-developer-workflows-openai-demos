# Bethany's Pie Shop

A beautiful and modern website for Bethany's Pie Shop, featuring a responsive design with carousel functionality, shopping cart, and product showcase.

## Features

- **Responsive Design**: Works seamlessly across desktop, tablet, and mobile devices
- **Image Carousel**: Dynamic hero section with automatic image rotation
- **Product Grid**: Showcase of featured pies with add-to-cart functionality
- **Navigation**: Dropdown menu for easy product browsing
- **Shopping Cart**: Integrated cart system for online ordering
- **Contact Page**: Customer service and location information

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Node.js (for local development server)

## Getting Started

### Prerequisites

- Node.js (for running the development server)
- A modern web browser

### Installation

1. Clone the repository:
   ```bash
   git clone <your-github-repo-url>
   cd bethanys-pie-shop
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open your browser and navigate to `http://localhost:3030`
